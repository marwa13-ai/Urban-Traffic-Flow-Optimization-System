╔══════════════════════════════════════════════════════════════════╗
║         THEORETICAL COMPLEXITY SUMMARY                        ║
╚══════════════════════════════════════════════════════════════════╝

  Algorithm          Time Complexity   Space   Route Quality
  ─────────────────  ────────────────  ──────  ─────────────
  BFS                O(V + E)          O(V)    Min hops (not min cost)
  Dijkstra (array)   O(V²)             O(V)    Optimal (min cost)
  Dijkstra (heap)    O((V+E) log V)    O(V)    Optimal (min cost)
  Congestion-Aware   O(V²)             O(V)    Near-optimal (avoids jams)

  Graph Representation:
  Adjacency List     O(V + E)  space   O(E)    edge traversal
  Adjacency Matrix   O(V²)     space   O(1)    edge lookup

  Edge weight update:
  List:   O(E/V) avg to find edge, then O(1) update
  Matrix: O(1) direct update — superior for frequent updates

  Rerouting: incremental updates avoid full recomputation;
  only affected portions of the priority queue are revised.
